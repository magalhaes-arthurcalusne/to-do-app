# # To-do List — JavaScript Vanilla

Projeto desenvolvido por mim aos 15 anos como parte da minha jornada de aprendizado em programação.

## Sobre o projeto

Uma aplicação de lista de tarefas criada para praticar os fundamentos do desenvolvimento web e a manipulação do DOM com JavaScript.

## Funcionalidades

- Adicionar tarefas pelo botão ou pela tecla Enter.
- Impedir a adição de tarefas vazias.
- Marcar e desmarcar tarefas como concluídas.
- Excluir tarefas.
- Exibir o total de tarefas e a quantidade de tarefas concluídas.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript Vanilla (JavaScript puro, sem frameworks)

## Objetivo

Praticar lógica de programação, eventos, manipulação do DOM e atualização dinâmica da interface.
